# RMP-EJ
A descriptive analysis of the sociodemographic composition of neighborhoods around chemical facilities and accidents in the United States.

The final study is published as follows:
Cook, Karlee, Dennis Guignet, Robin R. Jenkins, and Margaret Sugg. 2026. Disproportionate Environmental Risks: A Descriptive Analysis of Chemical Facilities and Accidents in the U.S. Applied Economic Perspectives and Policy, forthcoming. 

This repository includes the Stata code used to calculate relevant descriptive statistics and estimate the corresponding regression models (RMPNatl_EJ_analysis2026_09_12_CLEAN.do), and a compressed file containing the main dataset (Final_Panel_5yrACS_RMPcnts.7z).
